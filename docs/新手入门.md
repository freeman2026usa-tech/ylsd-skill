# ylsd-skill 新手入门

ylsd-skill 是一套免费的外贸获客技能，一共十三个：

获客方案、获客方向、开发信体检、写信提示词、写开发信、找相似买家、官网投流体检、投流策略、对话总结、回客户的信、客户背调、发信前邮箱检查、产品词和搜索词。

## 装

1. 到 GitHub 或 Gitee 搜 ylsd-skill 下载。

2. 按你用的 AI 软件装技能的方法装进去。

3. 装完后，新开一个对话。

## 第一次怎么用

输入：

```text
/ylsd 新手入门
```

它会说明你可以给什么、它怎么处理、会拿到什么。

也可以直接把东西交给 /ylsd：

```text
/ylsd 这是我们的官网 https://…，想开发欧洲，不知道先打哪个国家
/ylsd 这封开发信发了两百封没人回，帮我看看：（粘信）
/ylsd 官网 https://…，打德国的进口商，给我一条放进批量发信软件的写信提示词
```

不打 `/ylsd` 也行：直接说你要什么，AI 会自己挑技能。打 `/ylsd` 更稳。

1. 它先告诉你这次用哪个技能、会给你什么，然后开始处理。

2. 缺什么事实，它会先问你。你答完后，它接着做。

## 已经知道要做什么

直接打那个技能的命令，后面跟材料：

```text
/ylsd-plan 官网 https://…，想开发东南亚
/ylsd-target 官网 https://…，该先打哪个国家、哪类客户
/ylsd-check 这封信帮我看看：（粘信）
/ylsd-prompt 官网 https://…，买家是美国的品牌方
/ylsd-write 官网 https://…，买家是 https://…（对方官网），收件人是采购经理
/ylsd-similar 这是我同行 https://…，看看他在打哪类客户
/ylsd-site 官网 https://…，看看能不能投广告
/ylsd-ads 官网 https://…，一个月 1 万，打德国和土耳其，主推可打印自粘膜
/ylsd-recap 把这次对话总结一下，发给同事
/ylsd-reply 客户回了这封，怎么回：（粘信）
/ylsd-intel 这家靠不靠谱 https://…
/ylsd-mailbox 发信域名 xxx.com，邮箱用了两个月，一天 30 封
/ylsd-keywords 自粘乙烯膜英文叫什么，买家会搜什么词
/ylsd-site 我的站 https://…，同行 https://…，比一比
```

## 十三个技能各做什么

| 命令 | 中文名 | 你给 | 你拿到 |
| --- | --- | --- | --- |
| /ylsd-plan | 获客方案 | 官网，再答几个问题 | 八章获客方案：先打哪几个市场、主推哪款、谁在买、怎么找他们、信怎么写、第一周做什么、红线 |
| /ylsd-target | 获客方向 | 官网，再答三个问题 | 重点地区前三、重点客户类型前三、先不打的，每条带依据 |
| /ylsd-check | 开发信体检 | 一封你写的开发信 | 缺什么事实、哪句模板腔、主题行、结构、合规风险，逐句改法 |
| /ylsd-prompt | 写信提示词 | 官网或公司事实，加要打的买家类型 | 一条给 AI 批量发信软件用的写信提示词：你的事实写死，买家信息留成变量，软件给每家按它写 |
| /ylsd-write | 写开发信 | 我方官网或事实，加一家买家的官网或信息 | 一封英文开发信：三个主题行备选、正文、署名，末尾写用了哪些事实 |
| /ylsd-similar | 找相似买家 | 一家同行或客户的官网，加你自己的官网 | 这家的买家画像、找同类的特点、3 家样例（公司名、官网、来源页、像在哪、证据档）让你确认方向、一组搜索串；给的是同行时多一句它打哪类客户、你撞还是避 |
| /ylsd-site | 官网投流体检 | 官网 | 投流配件表：五类配件每项有、没有、没查到，加一句看到了什么；投流前必须补的最多三行；没查到的怎么自己查 |
| /ylsd-ads | 投流策略 | 官网，加一个月预算、目标国家、主推产品 | Google 投流开局方案八块：先补的配件、账户怎么分、词怎么分组和否词、落地页对应、预算怎么切、第一个月看什么数、停损、红线 |
| /ylsd-recap | 对话总结 | 这次对话 | 一份总结，先短版六行后长版四块：定了什么、没定什么、下一步、用了什么；说发给谁就按谁的口吻 |
| /ylsd-reply | 回客户的信 | 一封客户来信 | 判是哪种（新询盘、对开发信的回复、说贵了、要样品、婉拒、退订）；回信草稿；回信前要问对方的问题；下一步。新询盘先判真假和质量 |
| /ylsd-intel | 客户背调 | 一家买家的官网，或公司名加国家 | 五块：这家是谁、真不真、买不买得起、谁管采购（只有职位）、可疑的地方；末尾值不值得发信加信里能引的两个事实 |
| /ylsd-mailbox | 发信前邮箱检查 | 发信用的域名，加邮箱用了多久、一天发几封 | SPF、DKIM、DMARC 三样有无；爬坡表；退信超一成怎么查的三步 |
| /ylsd-keywords | 产品词和搜索词 | 产品中文名，或在用的搜索词 | 词包：英文名、同义词、买家搜的词、下游行业词、阿里标题、HS 编码候选；或每个搜索词一行判断和换法 |

它们不做的：找联系人、找邮箱、发信、给买家打分排序、代投广告。

获客方案、获客方向、投流策略这三个，分步来：

1. 先读你的官网，摆一张摸底表给你改。

2. 再问你几个问题，一次问一组。

3. 然后出结果。

其余十个：

1. 材料给齐了，直接出。

2. 缺一样，就问一句。

一个技能做完就结束，不替你决定下一步。

要接着做别的，再输入 `/ylsd`。它会看对话里已有的东西，不让你重说一遍。

## 视频里的编号

视频末尾报了三位数的，输入 /ylsd 加那个数，比如 /ylsd 012。

它会读取那条写好的指令，当场执行。

编号从 GitHub 或 Gitee 读取，软件要能上网。

## 更新，或者出了问题

两种办法，任选一种：

- 对 AI 说“更新 ylsd”，它按你的装法更新。
- 重新下载一遍，覆盖原来的文件夹。

更新完，新开一个对话。

/ylsd 每天第一次打开时，会查一次有没有新版。

有新版时，它会在回复末尾提醒。回 1 就更新。
