## ylsd-skill 是什么

ylsd-skill 是一套免费的外贸获客技能。

把它装到支持技能的 AI 软件里，就能在对话里直接用。

出品：WiseLeapp，官网 www.wiseleapp.com。装好后你可以让 AI：

- 读你的官网，再问几个问题，出一份获客方案：先打哪个市场、谁在买、怎么找、信怎么写、第一周做什么
- 读你的官网，问三个问题，告诉你重点开发哪类客户、哪几个地区，每条带依据
- 给你写好的开发信做体检，指出缺什么事实、哪句是模板腔、怎么改
- 按你的公司和你要打的买家，生成一条给 AI 批量发信软件用的写信提示词
- 给一家买家直接写一封英文开发信，写明用了哪些事实
- 给一家同行或老客户的官网，读出它是谁，给 3 家像它的样例让你确认方向，再给搜索串你自己去搜
- 查你的官网投流前的配件齐不齐：追踪码、询盘入口、落地页、语言版本，缺的排出先后
- 按官网、预算、国家、主推产品，出一份 Google 投流的开局方案
- 把这次对话整理成能直接发出去的总结：
  - 定了什么、没定什么、下一步
- 粘一封客户来信（询盘、对开发信的回复、说贵了），判是哪种，出回信草稿和要问对方的问题
- 给一家买家的官网，查它真不真、买不买得起、谁管采购、有没有可疑的地方
- 查发信用的域名三样记录有没有，新邮箱一天能发多少，退信多了怎么查
- 给产品中文名出英文名、买家搜的词、阿里标题；粘搜索词逐条判对不对
- 给我的站加同行站，出逐项并排的对比表

## 安装

1. 到 GitHub 或 Gitee 搜 ylsd-skill 下载。

2. 按你用的 AI 软件装技能的方法装进去。

3. 装完后，新开一个对话。

## 快速开始

输入 `/ylsd`，后面跟你的东西，不用先选技能：

```text
/ylsd 这是我们的官网 https://…，想开发欧洲，不知道先打哪个国家
```

不打 `/ylsd` 也行：直接说“我们官网是…，想开发欧洲”，AI 会自己挑技能。

打 `/ylsd` 更稳。

第一次用，可以先输入 `/ylsd 新手入门`。

1. 它先说这次用哪个技能、给你什么。

2. 然后开始。缺的事实它会问。

3. 你回答后，它会接着做。

## /ylsd 怎样安排技能

1. /ylsd 会读你给的东西和你说的话。

2. 它按每个技能说明书开头写的“接手什么、交出什么”挑技能。

3. 一个技能够用，就只用一个。

4. 你要的东西缺前一步时，它先安排前一步，再安排这一步。开做前，它会说一句怎么安排。

常见的对应：

| 你说要什么 | 你给的是什么 | 走哪个 |
| --- | --- | --- |
| 要完整方案、怎么开始、第一周做什么 | 官网、公司介绍 | ylsd-plan |
| 该打哪类客户、哪个国家、先打哪 | 官网、公司介绍 | ylsd-target |
| 这封信行不行、怎么改、为什么没人回 | 一封开发信 | ylsd-check |
| 要一条给批量发信软件用的写信提示词 | 官网或公司事实，加要打的买家类型 | ylsd-prompt |
| 给这家买家写一封信 | 我方官网或事实，加一家买家的官网或信息 | ylsd-write |
| 找更多像某家的买家、看同行在打谁 | 一家同行或客户的官网，加你自己的官网 | ylsd-similar |
| 官网能不能投、追踪码装没装 | 官网 | ylsd-site |
| 要投流方案、预算怎么分、投哪国 | 官网，加预算、国家、主推产品 | ylsd-ads |
| 总结一下、整理成能发的 | 这次对话 | ylsd-recap |
| 这封客户来信怎么回、询盘怎么回、客户说贵了 | 一封客户来信 | ylsd-reply |
| 这家靠不靠谱、值不值得发信、是不是骗子 | 一家买家的官网或公司名加国家 | ylsd-intel |
| 邮箱能不能发、一天发多少、退信多怎么办 | 发信用的域名；问一天发多少的，再加用了多久、现在一天发几封 | ylsd-mailbox |
| 产品英文名叫什么、搜索词对不对 | 产品中文名，或在用的搜索词 | ylsd-keywords |
| 我的站跟同行比差在哪 | 我的站加一到三个同行站 | ylsd-site |

1. 只给一个网址，什么都没说，它先问一句这是谁的网址。

2. 粘一封信，它会看是你写的，还是客户来的。

3. 两样都对不上时，它会问一句。

## 全部技能

| 命令 | 用途 |
| --- | --- |
| [`/ylsd`](skills/ylsd/SKILL.md) | 入口。转给对应技能；输入三位数编号时执行对应的指令 |
| [`/ylsd-plan`](skills/ylsd-plan/SKILL.md) | 获客方案。读官网，问几个问题，出八章方案加第一周清单 |
| [`/ylsd-target`](skills/ylsd-target/SKILL.md) | 获客方向。读官网，问三个问题，告诉你重点开发哪类客户、哪几个地区，每条带依据 |
| [`/ylsd-check`](skills/ylsd-check/SKILL.md) | 开发信体检。五项检查加逐句改法 |
| [`/ylsd-prompt`](skills/ylsd-prompt/SKILL.md) | 写信提示词。按你的公司和买家类型出一条给 AI 批量发信软件用的写信提示词 |
| [`/ylsd-write`](skills/ylsd-write/SKILL.md) | 写开发信。给我方事实和一家买家的信息，直接写一封，写明用了哪些事实 |
| [`/ylsd-similar`](skills/ylsd-similar/SKILL.md) | 找相似买家。给一家同行或客户的官网，加你自己的官网，读出它是谁，给 3 家像它的样例让你确认方向，再给搜索串；不给联系人、不出名单 |
| [`/ylsd-site`](skills/ylsd-site/SKILL.md) | 官网投流体检。查追踪码、询盘入口、落地页、Google 收不收、语言版本五类配件，每项有、没有、没查到；加同行站就出对比表 |
| [`/ylsd-ads`](skills/ylsd-ads/SKILL.md) | 投流策略。按官网、预算、国家、主推产品出 Google 投流开局方案八块，不代开户不代操作 |
| [`/ylsd-recap`](skills/ylsd-recap/SKILL.md) | 对话总结。定了什么、没定什么、下一步、用了什么四块，先短版后长版 |
| [`/ylsd-reply`](skills/ylsd-reply/SKILL.md) | 回客户的信。先判是询盘、对开发信的回复、说贵了、要样品、婉拒还是退订，再出回信草稿、要问的问题、下一步 |
| [`/ylsd-intel`](skills/ylsd-intel/SKILL.md) | 客户背调。这家是谁、真不真、买不买得起、谁管采购、可疑的地方，值不值得发信；只列职位不给联系方式 |
| [`/ylsd-mailbox`](skills/ylsd-mailbox/SKILL.md) | 发信前邮箱检查。域名 SPF、DKIM、DMARC 有无，新邮箱爬坡表，退信超一成怎么查 |
| [`/ylsd-keywords`](skills/ylsd-keywords/SKILL.md) | 产品词和搜索词。给产品名出英文名、买家搜的词、阿里标题、HS 编码候选；粘搜索词逐条判 |
| [`/ylsd-update`](skills/ylsd-update/SKILL.md) | 更新。把 ylsd-skill 更新到最新版，不动别的技能 |

它们不做：找联系人、找邮箱、发信、给买家打分排序、代投广告。

一个技能做完就结束，不替你决定下一步。

要接着做别的，再输入 `/ylsd`。

每个技能的适用时机和输入示例见[新手入门](docs/新手入门.md)。

## 使用视频里的三位编号

视频里拿到三位编号后，输入：

```text
/ylsd 012
```

把 `012` 换成视频给出的编号。

使用时，编号内容会从 GitHub 或 Gitee 读取。

AI 软件要能上网。

## 更新

两种办法，任选一种：

1. 对 AI 说“更新 ylsd”，它会按你的装法更新。

2. 或者重新下载一遍，覆盖原来的文件夹。

更新完后，新开一个对话。

/ylsd 每天第一次打开时，会查一次有没有新版。

有新版时，它会在回复末尾提醒，回 1 就更新。
