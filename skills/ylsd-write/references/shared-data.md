# 共享数据格式

对话里跑出来的中间产物有十一样。哪个技能先产出，后面的技能对话里见到就直接用，不重做。每样的栏写死在这里，加栏可以，改名、删栏不行，不然别的技能接不上。每条信息带 marks.md 里的标记。

## 公司事实清单

| 栏 | 写什么 |
| --- | --- |
| 中文名、英文名、地址、官网 | 官网读到的照原样；读不到的问，没有写“未提供” |
| 一句简介 | 做什么、主营产品、优势，一句 |
| 产品大类 | 有哪几类；这次重点做哪一类（只有用户能定） |
| 产品线 | 重点大类下的主要产品，每个一个地道的英文名加一句卖点 |
| 优势和认证 | 产能、年限、证书、大客户，照原话不润色 |
| 现有市场 | 官网写了卖到过、有客户或有项目的国家；只是提到的标“提到”；只写“全球”记“没写” |
| 规模线索 | 员工数、厂房面积、成立年份，没有不猜 |
| 品类 | 工业品、消费品、大宗原料三选一，判断不了按工业品 |

## 用户答案

| 栏 | 写什么 |
| --- | --- |
| 第几个问题 | 问题库里的那一条 |
| 原话 | 他怎么答的 |
| 分类 | [他说] 事实，或 [他认为] 判断 |

## 市场排序

| 栏 | 写什么 |
| --- | --- |
| 候选从哪来 | 他想开发的；现有客户所在的；同行官网和平台上出现的；官网提到的 |
| 每个候选五项 | 主推哪款；需求有没有；认证门槛；关税和原产地；同行密度和付款习惯，每项标已知、没查到或推测 |
| 前三和排后 | 前三各一句凭什么，排后各一句为什么先不打，带原则号 |

## 买家画像

| 栏 | 写什么 |
| --- | --- |
| 市场 | 哪个国家 |
| 身份 | 进口商、分销商、品牌方、零售商、工程项目、平台卖家之一 |
| 下游 | 拿产品做什么、卖给谁 |
| 看重什么 | 价格、交期、认证、起订量之类 |
| 备货季节 | 没来源写“判断不了，缺 X” |
| 从哪找供应商 | 没来源写“判断不了，缺 X” |
| 搜索串、判断表 | 获客方案第三章才有，别的技能产出的画像可以没有 |

## 一封信

| 栏 | 写什么 |
| --- | --- |
| 来源 | 用户粘的；写开发信技能写的；批量发信软件跑出来的 |
| 写给谁 | 哪类买家、哪个国家、哪家公司 |
| 主题行、正文、署名 | 原文 |
| 用了哪些事实 | 我方哪几条、对方哪一条 |

## 体检表

| 栏 | 写什么 |
| --- | --- |
| 五项 | 事实、模板腔、主题行、结构、合规风险点，各一个结论 |
| 原句和改法 | 逐句 |
| 最该先改的 | 一处 |

## 候选同类

| 栏 | 写什么 |
| --- | --- |
| 种子 | 拿哪家当样板找的，同行还是客户 |
| 公司名、国家、官网 | 照看到的写，不编 |
| 来源页 | 在哪个页面看到它的，网址 |
| 像在哪几点 | 跟特点清单对上的哪几条 |
| 证据档 | 官网看到了身份和业务；只在行业目录或展会名录看到；只有搜索摘要，待核实 |
| 条数 | 3 家样例，让用户确认方向，不是名单 |
| 不给 | 联系人、邮箱、电话、分数 |

## 投流配件表

| 栏 | 写什么 |
| --- | --- |
| 官网 | 查的是哪个站，谁的 |
| 五类 | 钱花了知不知道花哪；人来了问不问得上价；落地页；Google 收不收你的广告；投哪国就要哪国的 |
| 每项 | 有 / 没有 / 没查到，加一句看到了什么 |
| 必须补的 | 最多三行：转化代码、表单提交去向、落地页，缺哪个写哪个 |
| 没查到的怎么自己查 | 一行 |

## 背调结果

| 栏 | 写什么 |
| --- | --- |
| 哪家 | 公司名、国家、官网 |
| 五块 | 这家是谁；真不真；买不买得起；谁管采购（只有职位）；可疑的地方，每条带标记 |
| 结论 | 值得 / 先核一样再说 / 不值得，一句为什么 |
| 能引的事实 | 两条，各标来源页 |

## 域名三样

| 栏 | 写什么 |
| --- | --- |
| 域名 | 发信用的那个 |
| SPF、DKIM、DMARC | 各一格：有 / 没有 / 没查到，加一句查到了什么 |
| 爬坡 | 用了多久、一天发几封、该降到几封 |

## 产品词包

| 栏 | 写什么 |
| --- | --- |
| 英文产品名 | 一到两个，标 [官网] 或 [推测] |
| 同义词和别名 | 各标哪种场合用 |
| 买家搜的词 | 按身份分 |
| 下游行业词 | 每个下游一两个 |
| HS 编码候选 | 前六位，标 [推测] |
| 阿里国际站标题组合 | 两三条 |
| 别用的词 | 一行 |
