# 问题库

每条问题都标明类型：

1. 好答：选一个、填一个数，或回答是或不是，十秒能答完。

2. 好答问题每轮最多十道，排成一张表一次填。

3. 要想、要他回忆或描述的问题，一轮最多三个。

4. 挑哪几条、先后怎么排，按说明书第二步的匹配度算。

5. 摸底表（公司事实清单）里已有答案的，不再问。

## 产品和定位

| 问什么 | 字段 | 改哪一章 | 类型 | 什么时候问 |
| --- | --- | --- | --- | --- |
| 这次重点做哪一个产品大类 | 大类名一个 | 一、二、三、五 | 好答 | 摸底表留空让他填，没填就问 |
| 重点大类下主推哪两三个产品，OEM、ODM 还是自有品牌；定制的话打样几天、定制起订量 | 产品名加规格；三选一；打样天数；定制 MOQ | 一、三、五 | 要想 | 官网产品超十个，或没写加工方式 |
| 起订量和价格段位 | MOQ 加单位；FOB 单价区间 | 二、五 | 好答 | |
| 价格比同行高低；能让几个点 | 高／平／低；点数或“不能让” | 二、五 | 好答 | |
| 产能和交期 | 月产能加单位；交期天数 | 三、五 | 好答 | 工业品 |
| 认证有哪些，想打的市场要的证哪个没有 | 证书名，如 CE、UL、FDA、BSCI、ISO 9001、REACH、FSC | 二、八 | 好答 | 官网没列，或目标市场有硬性认证 |
| 售后和技术支持到哪一步 | 远程指导／派人到场／只换件／没有 | 三、四 | 好答 | 工业品 |
